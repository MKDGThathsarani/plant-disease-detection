# 🌿 Plant Disease Detection

**Confidence-Calibrated Framework for Smartphone-Based Plant Disease Detection**

## 🎯 Project Overview
A mobile application that detects plant diseases using on-device machine learning.

- **Disease Detection:** 38 plant disease classes (MobileNetV2)
- **Framework:** TensorFlow 2.x & Keras
- **Target Deployment:** TFLite & Flutter

## 🚀 Setup Instructions
1. Clone this repository.
2. Create a virtual environment: `python -m venv plant_env`
3. Activate it: `.\plant_env\Scripts\activate`
4. Install requirements: `pip install -r requirements.txt`
